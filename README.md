# Student Grade Management System

## Project Purpose

This is a simple Python program that helps calculate a student's average mark and grade.

## Problem Being Solved

Calculating marks by hand can take time. This program makes it easier by calculating the average and grade for the student.

## Technology Used

* Python

## Main Features

* Enter the student's name
* Enter three test marks
* Calculate the average mark
* Give the student a grade
* Show the student's name, average and grade

## How to Run the Program

1. Install Python on your computer.
2. Download this project from GitHub.
3. Open the project folder.
4. Open the terminal or command prompt.
5. Run:

```bash
python student_grades.py
```

6. Enter the student's name and marks when the program asks for them.
